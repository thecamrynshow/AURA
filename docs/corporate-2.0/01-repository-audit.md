# Repository audit — Corporate Website 2.0

Audit date: 16 October 2026. Production is `main` on GitHub Pages (`CNAME` `pneuoma.com`). This document describes the tree before the homepage redesign. The redesign lives on a review branch and is not deployed.

## What the site is

Static HTML, CSS, and JavaScript. There is no application framework and no shared component library. `package.json` only runs sitemap generation and lists Capacitor (iOS) plus Puppeteer as a dev dependency. Pages are hand-copied, including navigation.

Production hosting:

| Surface | Where |
|---|---|
| Website | GitHub Pages from `main`, root, `https://pneuoma.com` |
| API | `https://pneuoma.onrender.com` (`server/`) |
| Analytics | GA4 `G-TQGSNCV7Q2` via gtag, plus `conversion.js` events and Discovery dual-fire |
| Payments | Stripe checkout in `auth/subscribe.html`. PNEUOMA+ $9.99/month, Family $14.99/month |

## Homepage today

`index.html` is a classroom-regulation landing page: hero, Pattengill pilot, toolkit email form, platform grid, solutions, games, a “Research & Impact” block, a partner form, and a footer.

Problems for the new positioning:

- The title, description, keywords, Open Graph text, and JSON-LD describe one health-and-games product, including an FAQ answer that implies benefit for ADHD, anxiety, and autism. That is not a verified clinical claim.
- Navigation is a flat list of experiences, not Products / Solutions / Research / Company / Partners.
- The partner form (`main.js`) writes to `localStorage` and shows “Message Sent” without delivering the message.
- The research block cites polyvagal theory and HRV as if the product were validated. The only verified field evidence in-repo is the Pattengill kindergarten pilot.

What must stay available from the homepage: Games, Apps, Rituals, Classroom Sync, and the public resource URLs. Those pages are indexed and should not be removed.

## Design system

`styles.css` holds the tokens: dark backgrounds (`#07080d`, `#0d1117`, `#151b23`), teal `#64ffda`, Cormorant Garamond headlines, DM Sans body. It also styles the current homepage, so new layout classes should be prefixed. A global `prefers-reduced-motion` rule already shortens animations. Focus treatment and skip links are missing. Contrast of teal on the dark background is strong; muted gray `#6b7280` is the risky small-text color.

Shared partials do not exist. Changing `styles.css` layout rules would change every page that links it.

## Analytics

- gtag config `G-TQGSNCV7Q2` is in page heads.
- `conversion.js` binds `[data-pc-event]` to GA4 and to `PneuomaDiscovery` when present.
- Homepage events already in use: `cta_start_free_click`, `cta_request_pilot_click`, `classroom_sync_interest_click`, `cta_download_toolkit_click`.
- `POST /api/leads` stores email, source, and page only. It does not store a message body.

## Images

Almost no product screenshots are in the repo. Existing rasters are the logo, app icons, the founder photo at `platform/about/images/camryn-jackson.jpg`, and iOS splash assets. Authentic screenshots for this redesign were captured from the running products, not drawn.

## Claims that are safe to publish

- Company name PNEUOMA. Founder Camryn Jackson. Contact `camrynjackson@pneuoma.com`.
- Founding year 2024 is already in the homepage JSON-LD.
- Pitch deck (founder-supplied, already published): former school leader (Dean / Athletic Director); University of Michigan alumnus.
- Classroom Sync pilot, 4–21 May 2026, Mrs. Gill’s kindergarten, Pattengill Elementary, Lansing, MI. Public quote already on the homepage: “Absolutely helps, very effective. I’ll keep doing it daily during transitions.” Teacher-reported. Not a clinical study.
- Web games, rituals, Classroom Sync, labs modules, and the tech links are real routes or live URLs checked on 16 October 2026.
- Free games are capped at 3 sessions/day (`auth/protect.js`). Classroom Sync is on the free multiplayer list. PNEUOMA+ and Family prices are on `auth/subscribe.html`.
- Dean OS, Capture, and Discovery show a sign-in wall in a browser. Visualizer’s public homepage describes the product. Game Studios says The Campaigne is in development.
- Labs modules on the site: Resonance, Sonoluminescence, Tissue Optics, Acoustics, Somatics. They are interactive experiments.

## Claims that must not be published

- Customer logos, enterprise deployments, certifications, SOC 2, HIPAA, or security white papers. None are in the repo.
- Clinical validation, outcome percentages, or “helps ADHD / autism” as a result.
- A single unified application that contains every product.
- Discovery as a public product demo. The public screen is a private founder sign-in.
- App Store availability, unless re-checked. The apps page asserts five live App Store apps; that was not re-verified in this audit.
- Hardware and a public API. The current homepage marks both as not available.
