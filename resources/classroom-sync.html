Classroom Sync: One Teacher Leads, the Whole Class Breathes Together

Transitions, dysregulation, and scattered attention eat instructional time. Classroom Sync puts the same guided breathing routine on every student's screen at once — so your class resets together in 1–2 minutes.

The problem: transitions and dysregulation

Every teacher knows the moments: coming in from recess, settling after lunch, or a room that's wound up before a lesson. Trying to get 25 individual nervous systems to settle one by one is exhausting — and "calm down" rarely works. The result is lost minutes and rising stress for everyone.

The solution: synchronized regulation

With Classroom Sync, the teacher starts one routine and every connected device follows the exact same breath in real time. Instead of herding attention, you give the whole class a shared, visual rhythm to follow together. It runs in the browser — no download, no install.

School-safe by design: Classroom Sync supports regulation, helps students reset, and improves transitions. It is not a medical or clinical tool.

Proof: a real kindergarten classroom

In a three-week pilot in a Lansing, MI kindergarten, the teacher began running Classroom Sync daily during transitions — and kept going on her own.

How it works

  1. Teacher starts a session and shares a simple class code.
  2. Students join on any device by entering the code (or anonymously).
  3. Teacher picks one routine — Quick Ground, Transition, Focus Prep, Calm Down, and more.
  4. Everyone breathes together as each screen follows the same guided rhythm.
  5. Close and move on — a quick check, then straight into the next activity.

Use cases

  • After recess / lunch: settle an activated room before learning.
  • Before a test or focus block: a shared focus-prep breath.
  • Morning arrival: start the day calm and connected.
  • Whole-school SEL: a consistent, teacher-led regulation moment in every room.

Frequently asked questions

Do students need accounts or downloads?

No. Students join with a class code in any browser, and can join anonymously. There's nothing to install.

How many students can join a session?

Classroom Sync is built for whole-class use. A typical class joins on individual devices or you can project one screen for the room.

Is it free?

You can try Classroom Sync for free. Schools interested in wider rollout can request a pilot.

Does this make medical or clinical claims?

No. It supports everyday regulation, resets, and transitions. It is not a treatment and does not diagnose or cure any condition.
